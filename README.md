# An-Enhanced-Deep-Learning-Framework-for-Heart-Disease-Classification-using-Echocardiogram-Images
This project presents a hybrid deep learning framework for automated heart disease classification from echocardiogram images. The proposed approach combines VGG16 and InceptionNet to extract complementary image features and classify four categories: Angina, Cardiovascular Disease (CVD), Coronary Artery Disease (CAD), and Hypotension. The model was trained and evaluated using a dataset of 2,404 echocardiogram images, with performance assessed using accuracy, precision, recall, F1-score, and confusion matrices. The proposed hybrid model achieved an average accuracy of 93.75%, outperforming the individual VGG16 (93.17%) and InceptionNet (91.13%) models in the reported experiments.
